# pstack for Codex

Independent adaptation of **pstack by Lauren Tan (poteto)**. Original workflows and source are pinned and preserved with their MIT licenses; read [attribution](ATTRIBUTION.md).

Say **“Set up pstack for this environment.”** New users choose a reasoning budget; none is selected by the package. Existing explicit choices are preserved and can be changed. Native host tools are the default, optional local coding CLIs are disabled until chosen, and external APIs remain disabled. No server URL, tunnel, MCP connection or laptop callback is needed.

Use **“poteto-mode”** to apply the engineering workflow and **“recover this work”** after an interruption. See [first use](references/first-use.md), [execution contract](references/runtime-contract.md), [coverage](references/behavior-coverage.md), and [upstream updates](references/upstream-updates.md). Actual host and account capabilities must be verified; multiple OpenAI models do not provide cross-provider independence.
